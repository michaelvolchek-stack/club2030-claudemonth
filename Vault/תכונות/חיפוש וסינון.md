# חיפוש, סינון ומיון

## חיפוש (live)

דף `/search` ([[דפים וניווט#search]]) עם [[רכיבים#תצוגות (Client Views)|SearchViewClient]]: הקלדה עם **debounce**, קריאה ל-[[Server Actions#tasks.ts — משימות|searchTasks(query)]], והדגשת (`highlight`) ההתאמות בתוצאות.

## סינון ומיון

דף `/all` ([[דפים וניווט#all]]) עם [[רכיבים#תצוגות (Client Views)|AllViewClient]] — FilterBar + SortMenu. ה-state נשמר ב-**URL params** (shareable, מתמיד ב-refresh).

> [!info] טיפוסי סינון (`TaskFilters`)
> `status[]`, `priority[]`, `projectId`, `tagIds[]`, `fromDate`, `toDate`, `hasTime`, `search` — מועברים ל-[[Server Actions#tasks.ts — משימות|getTasks]].

> [!info] מיון (`TaskSort`)
> `field`: `dueDate` / `priority` / `createdAt` / `title` / `order` · `dir`: `asc` / `desc`.

> [!tip] מיון `order`
> שדה `order` תומך גם במיון ידני (drag-and-drop) דרך [[רכיבים#משימות|SortableTaskList]].
