# משימות חוזרות

משימה עם `isRecurring = true` ו-`recurringRule` (JSON כ-String). העורך: [[רכיבים#עריכה ובחירה|RecurringEditor]] בתוך [[רכיבים#משימות|TaskPanel]].

## מבנה הכלל (`RecurringRule`)

מוגדר ב-`src/types/index.ts`:

```ts
interface RecurringRule {
  freq: 'daily' | 'weekly' | 'monthly'
  interval?: number    // למשל כל 2 שבועות
  days?: number[]      // 0=ראשון … 6=שבת (weekly)
  dayOfMonth?: number  // 1-31 (monthly)
}
```

## תדירויות

| `freq` | שדות רלוונטיים | דוגמה |
|--------|----------------|-------|
| `daily` | `interval` | כל יום / כל 3 ימים |
| `weekly` | `interval`, `days[]` | כל שני וחמישי |
| `monthly` | `interval`, `dayOfMonth` | ב-1 לכל חודש |

> [!note] אחסון
> הכלל נשמר כ-`recurringRule: String?` ב-[[מודל נתונים#Task — לב המערכת|Task]] (JSON מסוריאלייז) — בהתאם למגבלת SQLite ללא JSON type מובנה.

> [!info] ימים בשבוע
> `days[]` משתמש במוסכמה `0=ראשון`, תואם ל-`Date.getDay()` של JavaScript.
