# Quick Add — הוספה מהירה בשפה טבעית

מנתח עברית ([[Server Actions#quickAdd.ts — ניתוח שפה טבעית|parseQuickAdd]]) שהופך שורת טקסט חופשי למשימה מובנית. ה-UI: [[רכיבים#משימות|QuickAddBar]] עם preview חי.

## פורמט

```
כותרת [תאריך] [!עדיפות] [#פרויקט] [@תגית] [~תכנון]
```

## טוקנים

| Token | משמעות | דוגמה |
|-------|--------|-------|
| `!1`–`!4` | עדיפות (דחוף→נמוך) | `!1` = דחוף |
| `#name` | פרויקט | `#עבודה` |
| `@name` | תגית | `@פגישות` |
| `~date` | תאריך תכנון (`plannedDate`) | `~היום` |
| `מחר` / `היום` / `מחרתיים` | תאריך יעד | `מחר` |
| `בעוד שבוע` / `בעוד 3 ימים` | יחסי | `בעוד שבוע` |
| `ביום שני` | יום בשבוע | `ביום שני` |
| `ב-15/6` | תאריך מוחלט | `ב-15/6` |
| `בבוקר`/`בצהריים`/`בערב`/`בלילה` | שעה | `בבוקר` → 09:00 |
| `HH:MM` | שעה מפורשת | `14:30` |

> [!example] דוגמאות
> ```
> לפגוש יעל מחר בבוקר !1 #עבודה @פגישות
> לשלם חשבון !2 ב-5 ביוני
> לכתוב דוח בעוד שבוע #עבודה ~מחר
> ```

> [!tip] תכנון מול יעד
> `~` קובע `plannedDate` (מתי לטפל), נפרד מ-`dueDate` (תאריך היעד). ראה [[מודל נתונים#Task — לב המערכת]].

## פלט

`parseQuickAdd` מחזיר `QuickAddResult`: `{ title, dueDate?, dueHasTime, plannedDate?, priority, projectName?, tagNames[] }` — שמועבר ל-[[Server Actions#tasks.ts — משימות|createTask]].
